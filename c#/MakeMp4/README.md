# MakeMp4

把「音频 + 图片」批量合成为 mp4 视频（Windows / WPF）。

## 依赖

- [ffmpeg](https://ffmpeg.org/)（`ffmpeg`，可选同目录的 `ffprobe`）
- [ImageMagick](https://imagemagick.org/)（`magick` / `convert`）

在界面里填 ImageMagick / ffmpeg 所在目录，程序就使用目录里的命令；目录留空时
退回 `PATH` 查找。

## 使用

1. 运行程序，选择**音频目录**（`歌曲名-作者.mp3`）与**图片目录**
   （`Image00001.jpg`，五位递增；图片目录里也可以放 mp4/mov/mkv/webm/avi 等
   视频片段，按自身时长整段接入，原声丢弃）。
2. 需要的话点「载入…」读取 `make_mp4.ini`（也可以用「保存配置…」写一份，
   字段与 `make_mp4.ini.example` 一致）；输出目录留空时为「音频目录\out」。
3. 点「开始生成」。已存在且大于 1KB 的 mp4 会跳过，勾选「强制重建」可重做。

## 流程

- 用 ImageMagick 渲染片头封面：歌名 / 作者各一行居中，缓存到
  `<输出目录>/covers/<歌曲名>.jpg`；渲染逻辑或配色配置变化后自动重建。
- 单张图片编成的小片段会缓存到 `<输出目录>/_cache`：按「图片文件名 + 秒数」命名，
  下次再抽到同一张图、秒数也一样时直接把缓存拷出来用，不再重编。缓存文件名还带一段
  编码配置签名（尺寸/帧率/编码器/CRF/preset/fit/补边色/每图秒数），设置变了会自动
  用新的缓存。只认缓存文件在不在，不校验大小、不联网下载。
- 用 ffmpeg 把随机顺序抽到的图片和视频片段各自做成一段小视频：图片按 `seconds`
  （片头封面用 `cover_seconds`）用 `-loop 1 -t` 写死时长，视频片段保留自身时长、
  原声丢弃；图片按 `fit` 决定是等比补边还是按宽/高铺满。各段参数一致，再 `concat`
  copy 拼成整条幻灯片，只在换图处强制关键帧，体积小、后面拷贝快。
- 最后把正片（封面之外的部分）copy 着循环铺满音频时长，封面只出现在片头
  一次，输出 `<输出目录>/<歌曲名>.mp4`。循环次数向下取整后剩下的零头不再从第一张图
  重播（那样片头会在片尾原样再出现一遍），而是把图片重新洗牌编一小段收尾，
  片尾是一段新顺序，既不重复片头也不紧挨着回放幻灯片结尾；收尾段第一张不会和
  前面最后一张相同，同一张图不会连着显示两次（那样看起来就是这张图显示时长翻倍）。

## 配置

字段示例见 `make_mp4.ini.example`。界面上的 `preset` 与「图片自适应」都是下拉框
（`preset` 可编辑，能填 NVENC 等其它编码器的值）。

- `preset`：x264/x265 的编码 preset，候选 `ultrafast` … `placebo`。
- `fit`：图片自适应方式，`contain` = 等比缩放、四周补边（默认）；`width` =
  宽度自适应、高度铺满，多出的宽度居中裁掉、不足处左右补边；`height` =
  高度自适应、宽度铺满，多出的高度居中裁掉、不足处上下补边。补边颜色用 `pad_color`。别名 `fit_mode` /
  `image_fit` / `image_adapt` / `adapt` / `resize` 同样认。

外部程序用目录配置：

- `magick_dir`：ImageMagick 安装目录，程序用里面的 `magick.exe` / `convert.exe`。
- `ffmpeg_dir`：ffmpeg 所在目录，程序用里面的 `ffmpeg.exe`，`ffprobe.exe` 也从
  这个目录查找。

两个目录留空时自动在 `PATH` 里查找。

## 日志

每次运行都会写 `<输出目录>/make_mp4.log`，逐条记录命令（`CMD`）、退出码
（`EXIT`）、命令输出（`OUT`/`PROBE`）、封面取舍（`COVER`）与产出文件及大小
（`FILE`）。封面出不来时把这份日志发出来就能看到卡在哪一步。
